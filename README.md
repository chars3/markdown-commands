# 📝 Principais Comandos Markdown (Sintaxe)

## 📄 Estrutura de Texto

| Sintaxe           | Resultado                          |
|-------------------|-------------------------------------|
| `# Título 1`      | Título de nível 1                  |
| `## Título 2`     | Título de nível 2                  |
| `### Título 3`    | Título de nível 3                  |
| `**negrito**`     | **negrito**                        |
| `*itálico*`       | *itálico*                          |
| `~~tachado~~`     | ~~tachado~~                        |
| `> citação`       | > citação                          |
| `---` ou `***`    | Linha horizontal (separador)       |

## 📋 Listas

| Sintaxe               | Resultado                      |
|-----------------------|---------------------------------|
| `- Item`              | Lista com marcadores (bullet)   |
| `* Item`              | Outra forma de marcador         |
| `1. Item`             | Lista numerada                  |
| `- Item\n  - Subitem` | Lista aninhada (indentada)      |

## 🔗 Links e Imagens

| Sintaxe                                   | Resultado              |
|-------------------------------------------|-------------------------|
| `[Texto](url)`                            | [Texto](https://url)   |
| `![Alt](imagem.png)`                      | Exibe imagem            |
| `[Texto][ref]` + `[ref]: https://url.com` | Link com referência     |

## 💻 Código

| Sintaxe                 | Resultado                            |
|-------------------------|---------------------------------------|
| `` `código` ``          | `código` inline                      |
| \`\`\`                  |                                       |
| código em bloco         | Bloco de código                      |
| \`\`\`                  |                                       |
| \`\`\`python            | Bloco com destaque para Python       |
| print("Olá")            |                                       |
| \`\`\`                  |                                       |

## ✅ Tabelas

| Sintaxe                                | Resultado                  |
|----------------------------------------|-----------------------------|
| `| Cabeçalho | Cabeçalho |`            | Cabeçalho                   |
| `|-----------|-----------|`            | Separador                   |
| `| Celula1   | Celula2   |`            | Linha da tabela             |

## 📌 Outros

| Sintaxe                        | Resultado                                  |
|--------------------------------|---------------------------------------------|
| `<!-- comentário -->`         | Comentário invisível no renderizado        |
| `\*caractere\*`               | Escapa símbolos especiais (exibe `*`)      |
| `:smile:`                     | Emojis (em plataformas compatíveis) 🙂     |
